风险与应对

答辩时主动讲风险，比被问出来更有说服力。

R-01 红米2 跑 Klipper 失败

1GB 内存跑 Python 服务容易 OOM。应对：主方案改为笔记本跑 Klipper，红米2 只做触屏，答辩讲双冗余设计。

R-02 硬件装配延期

软件先行开发，用模拟数据对接；W1 必须完成装配，否则整体顺延。

R-03 现场网络不稳定

演示模式兜底 + 备播视频 + 自带路由器组网，三保险。

R-04 视觉检测误报

阈值可调 + 连续两次才告警 + 定位为辅助提醒而非自动停机。

R-07 评委质疑与开源方案的区别

准备三层差异化表述：定位差异、架构差异、能力差异。
